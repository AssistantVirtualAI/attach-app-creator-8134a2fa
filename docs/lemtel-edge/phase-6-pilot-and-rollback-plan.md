# Lemtel Edge - Phase 6 pilot and rollback plan (future only)

1. Static validation and the Phase 1 Docker runtime validation have passed.
2. Non-production FusionPBX and private Edge prerequisites are approved.
3. A separately approved app compatibility release is available to a controlled pilot cohort.
4. Device-level authorization, capability and pilot approval are recorded.
5. The direct route is withdrawn for one approved device before future Edge pilot selection.
6. Only safe enumerated evidence is reviewed.
7. Rollback revokes the Edge assignment before restoring the existing direct route.
8. No expansion until pilot metrics and rollback evidence are accepted.

No step is executed in Phase 6. These contracts collect no customer numbers, audio, recordings, messages or credentials.

Pending gate: the Phase 1 Docker runtime validation from `docs/lemtel-control-plane/local-development.md` is still pending. It blocks every runtime, deployment, integration, gate and pilot action.

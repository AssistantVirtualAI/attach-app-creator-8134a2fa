# Lemtel Edge - Phase 6 release and update safety

- The published iOS, Android and desktop Lemtel applications are not modified in Phase 6.
- A future client capability or update phase requires a separately reviewed release plan for every platform and cannot force a global update or cutover.
- Users not enrolled in a future pilot remain on the existing route.
- Automatic update behavior, App Store / Play Store release mechanics and desktop release assets are outside Phase 6.
- Phase 6 causes no forced sign-out, password reset, credential replacement or silent route change.

Pending gate: the Phase 1 Docker runtime validation from `docs/lemtel-control-plane/local-development.md` is still pending. It blocks every runtime, deployment, integration, gate and pilot action.

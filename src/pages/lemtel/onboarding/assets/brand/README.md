# Logos de marque (optionnels)

Déposez ici le logo officiel Cloudflare téléchargé depuis la page de marque de Cloudflare, sous le nom
`cloudflare-logo.svg`. Le panneau « Bascule automatique » l'affiche automatiquement au prochain build.
Sans ce fichier, le panneau montre une icône de nuage générique accompagnée du libellé « Cloudflare ».
Le logo n'est pas redessiné dans le code.
